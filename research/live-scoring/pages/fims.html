Welcome to FIM Visualization

FIM Visualization is an interactive flood inundation mapping tool. Use the panel on the left to load and explore flood data. Clicking on map features displays descriptions and metadata in the info panel. The sections below describe each feature.

Flood Map Set (Scenario)

Load pre-computed flood inundation extents from the scenario selector. Use the slider to step through flood stages or time steps. Custom extent rasters (single-band GeoTIFF) can be uploaded via the Add Scenario uploader. Uploaded scenarios appear directly in the Map Layers panel alongside built-in scenarios and can be toggled or removed there.

Flood Depth

Overlay a continuous water depth surface. Custom depth rasters can be uploaded via the depth file uploader and will appear in Map Layers. Use Image Tools to change palette, mask an area for statistics, or hover to read values.

Velocity

Display flood velocity magnitude as a raster layer. Upload custom velocity GeoTIFFs via the velocity file uploader; they appear in Map Layers for toggling. Analysis tools are available in Image Tools.

Ensemble

View probabilistic flood extents across multiple model runs. Upload ensemble GeoTIFF files via the ensemble file uploader; uploaded files are listed in Map Layers.

User Files

Upload your own spatial data to display alongside existing layers. All uploaded files are stored locally in the browser, persist across sessions, and appear in the Map Layers panel where they can be toggled and removed. Use the upload button or drag-and-drop. Supported formats:

  • GeoJSON — Vector features with property descriptions viewable on hover via Layer Tools.
  • KML / KMZ — Vector data with embedded styling and feature descriptions.
  • GeoTIFF — Single-band raster; palette and statistics via Image Tools.
File Uploaders

Each layer type has a dedicated uploader in the left panel. All uploaded files are stored in the browser and persist across sessions. Once uploaded, files appear as checkboxes in the Map Layers panel and behave the same as built-in layers.

  • Add Scenario — Upload a single-band GeoTIFF as a custom flood extent scenario. Appears under Flood Map Set (Scenario) in Map Layers.
  • Depth — Upload a depth raster GeoTIFF. Appears under Flood Depth in Map Layers. Activates Image Tools on load.
  • Velocity — Upload a velocity magnitude raster GeoTIFF. Appears under Velocity in Map Layers. Activates Image Tools on load.
  • Ensemble — Upload a multi-run probabilistic extent GeoTIFF. Appears under Ensemble in Map Layers.
  • User Files — Upload GeoJSON, KML/KMZ, or GeoTIFF. Files appear under User Files in Map Layers and activate Image Tools or Layer Tools depending on type.
Image Tools & Layer Tools

Opens automatically when a raster or vector layer is loaded. Raster layers get palette selection, statistics, and draw-mask tools. Vector layers get color themes, opacity, feature metrics, and property hover.

Damage Estimation

When a flood extent is loaded, enable damage estimation to see building-level loss estimates based on HAZUS methodology. Toggle metric categories from the right-side panel.

Comparison

Load two flood scenarios or user files side by side. Overlap regions are highlighted to show areas of agreement or divergence between datasets.
