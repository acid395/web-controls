Try the widget on any site

For comparing the library against the extension on the same pages. A site that installs the library gets this without a bookmarklet; this just lets you put it on sites you don't own.

1. Drag this to your bookmarks bar:

web-controls widget

2. Keep node widget/demo/serve.js running.

3. Open a site, for example drought.gov, then click the bookmark. The widget's button appears in the bottom-right corner. Press Load model once; after that the weights come from the browser's cache.

Chrome may ask whether the site can reach devices on your local network. That's the bookmarklet loading the widget from localhost. A site that installs the library serves the file itself, so its visitors never see that prompt.

Where it won't load

Sites whose Content-Security-Policy limits script-src will block the bookmarklet. If they limit connect-src, they also block the model download from Hugging Face. When that happens the bookmark shows an alert. A site that installs the library sets its own CSP to allow both; the README lists the exact directives.

Turn the extension off for that tab while you compare. Both put the same page agent into the page, and two copies get in each other's way.

Steps that load a new page end the run. The widget lives in the page and goes with it, but the extension doesn't. The panel reopens on the next page if the bookmark is clicked again, with the history kept.
