This site

Ask

Two kinds of request. Control the page you're on ("set the parameter to gage height"), or ask a question answered from USGS's public API, with no clicking and no matter which page is open ("what's the gage height in Alaska"). Both are instant when recognized, with no model involved at all. Anything it doesn't recognize says so rather than guessing - the local model that would handle the rest is off by default (see Debug tools), because it downloads gigabytes and slows the machine.
Debug tools (call things directly, bypass Ask)

Run a tool call by hand (no model)

Feeds a tool call straight into the same path a model's output takes: tool-name lookup, argument remapping, injection, the page bridge. No model, no download, no key - isolates "does execution work" from "is the model any good." Tool names come from TOOL_DEFS, e.g. usgsSetParameter, siteGraphParameter, noaaSetBasemap, pageSelectOption.

Show the model's context

Exactly what a model would be handed for this page: the tools it can pick from, plus env-vocab and (on GENERIC sites) the live inventory with real selectors.

Local model (off by default)

Off unless you switch it on: it downloads several gigabytes and saturates the GPU while running, which slows the whole machine, not just this extension. Everything above works without it.
