Local model

A local model, which needs WebGPU and saturates it while running. The default is Llama 3.1 8B - about 5GB on first load, and worth it for anything with several steps in it. A machine that cannot hold it falls back to Qwen2.5 1.5B on its own and says so below. Everything else here works without a model at all. The picker is at the top of the panel, beside what it is doing. Prefix any question with model: to put it to the model directly, type use 1b, use 3b, use 7b, use 8b or use 9b to change which one plans, and speed test to measure what this machine can actually manage.
Which model plans. Every step of an instruction is one turn of it, so this is most of what waiting for an instruction is, and it is also most of what it costs the machine - the 3B took Chrome down on a GPU that could not hold it beside a heavy page. A smaller one answers sooner and picks the wrong control more often.

Compare the planners

Reworded asks for controls this page actually has, put to both planners. Neither acts - each only chooses - so it is safe to run on a live page and gives the same answer twice. The question it settles: does the model reach controls the keyword scorer cannot, and what does that cost per decision.
